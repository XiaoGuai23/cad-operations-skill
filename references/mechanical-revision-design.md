# 二维机械图修订设计方法

适用于 PDF／截图批注修订、标注编辑行为要求，以及用户指定的交点分段。
按任务选用下列方法；已有图纸默认按第 4 节直接修改，普通格式转换不需要建立完整修订台账。
本文件定义工作方法和验收要求，不代表当前 Python 核心已实现全部数据字段或操作。
实现前检查实际接口；未支持的要求应记为待实现或未验证，不能用外观相似的结果代替。

## 1. 批注逐条追踪与验收

开始修改前，把有效批注写入任务目录内的修订台账，例如
`work/revisions.json`。已有等价记录时直接复用；不要把台账字段强塞进不支持它们的
`DrawingSpec`。每条记录至少能回答：

| 内容 | 记录方法 |
| --- | --- |
| 哪条要求 | 稳定的批注 ID、用户原文、来源消息或文档位置 |
| 针对哪一版 | 被批注文件的路径和哈希、实际修改基准及其来源关系 |
| 哪个区域 | 页码、页面尺寸、区域坐标、单位、原点方向；截图另记裁切和缩放信息 |
| 修改什么 | 视图与零件／几何稳定 ID、当前对象映射、修改前状态与预期变化 |
| 怎样算改好 | 可检查的几何关系或编辑行为、数值容差依据、相关旧要求 |
| 完成证据 | 待处理／待澄清／已修改待验证／已验证／被新要求取代，及对应输出证据 |

PDF 区域用于查找候选对象，不能作为删除框内所有实体的指令。定位时结合视图、
零件、中心线和边界；记录从页面到绘图坐标的变换。不要把旧版本的截图坐标直接套到
新版本上。句柄只作为当前文件映射，不能代替跨版本稳定 ID；临时建立的 ID 要保留
来源实体和匹配证据。目标仍有歧义时只询问影响修改的关键点，继续处理独立且明确的条目。

把“下移到边缘”“恢复原长”“删除标注”等文字转成具体完成条件。例如：

- “螺钉尾部触及橡胶垫下边缘”：先明确尾部和垫片边缘，检查指定端点重合；不能仅凭截图看着接近。
- “螺钉头向上延伸，底部不延伸”：固定底边，检查顶边变化和相邻轮廓、填充的完整性。
- “删除标注和标注线”：检查对应文字与引线均消失，相关轮廓仍存在。

“上一版”必须定位到实际版本及参数；不能猜长度。仅当新要求确实改变旧要求时，
记录取代关系和原因。例如同一批标注先要求拆散、后明确要求视频中的联动拖动，应采用
最新编辑行为；已经确认的其他几何修改继续有效。

修改后从最终导出文件读取检查结果，并对涉及外观的条目保存同视图、同尺度的局部
前后对照。只有完成条件及必要证据均满足，才能标为已验证；生成了新文件不等于完成批注。

## 2. 标注的编辑行为先明确，再选择对象

根据最新用户要求区分原生可拖动标注、拆散后独立编辑的文字／线条，以及与实体几何
关联的尺寸。已有明确要求时沿用，不为每条标注重复确认。对需要夹点联动移动的任务：

- 尺寸保留或生成对应类型的原生 `DIMENSION`；联动文字引线优先使用原生 `MULTILEADER`。
- 普通说明文字继续使用可编辑 `TEXT`／`MTEXT`；不将整张图或标注包装成普通块来替代编辑行为。
- 记录实际测量起点、终点／圆心或半径对象、方向、尺寸线及文字位置、单位、样式、
  前后缀、公差、配合、文字覆盖和预期夹点行为。引线记录箭头目标、折点、文字和连接方式。
- 保留已有数值及工程语义。只有确认显示数值对应真实测量量时，才能改用测量占位符；
  不能用“替换第一个数字”的方法处理孔数量、直径或公差。
- 直径、半径、孔数、孔距圆等不能伪装成无关的普通线性尺寸。当前规格接口表达不了时，
  保留可追溯的设计要求并明确能力缺口，不声称原生交互已完成。

例如“拖动尺寸文字时尺寸线一起移动、测量起点不动”可使用相应的文字移动模式
（AutoCAD 中 `DIMTMOVE=0`），但仍需从实际对象和交互结果核验。
“夹点可移动”不证明尺寸随实体几何自动更新；只有建立并检查关联引用、移动关联实体后
验证尺寸更新，才能宣称几何关联。用户明确要求拆散标注时，按该要求交付并说明联动行为的变化。

原生尺寸内部用于显示的匿名块不等同于模型空间的普通 `INSERT` 块参照；不要为满足
“不是块”而破坏原生尺寸。普通块的允许范围按本次任务确定，不能把零 `INSERT` 变成所有图纸的通用条件。

验收分两层：从保存并重新打开的 DXF／DWG 检查对象类型、真实测量值、文字与引线连接、
样式和端点；对新引入或修改的交互类型，在单独副本中做代表性夹点操作，确认移动结果与
约定一致。报告哪些对象逐个做了结构检查、哪些交互只做了抽样；试拖副本不得覆盖正式排版。

## 3. 按需交点分段与修改后核验

只有用户要求分段或任务确有必要时才启用；单纯修改尺寸位置无需把全图拆散。
先声明参与对象、交点范围和容差来源，再执行几何运算：

- 默认处理本次范围内的实体轮廓。保留 `HATCH` 及其填充语义，原生尺寸和引线也保持完整。
  若轮廓需要在标注交叉处断开，可把标注的显示几何作为只读切分参考，不反向切碎标注。
- 对直线、圆弧以及实际支持的其他曲线，处理交叉点、T 形接点、相切点和重合区间。
  不支持的曲线应报告，不能静默遗漏或转成未经批准的近似线段。
- 按绘图单位和数值精度设置容差，避免重复切点、零长度或极短伪线段；圆弧判断区分
  长度容差与角度容差。重复运行应得到等价拓扑，不持续增加碎段。
- 保存源几何 ID 到最终线段／句柄的映射，保留图层、线型、线宽、颜色等属性。
  切分后实体数量会改变，不能继续用“前 N 个实体属于原始视图”的假设归组。

每轮验证同时覆盖本次有意修改的范围，以及受影响的相邻区域和仍有效的历史批注：

1. **意图检查**：本轮批注逐条满足完成条件；旧要求除明确被取代者外继续成立。
2. **几何检查**：纯分段前后线／弧的覆盖范围保持一致；检查漏分交点、重复段、短段、
   孔与轮廓连通关系。总长度只是辅助指标，不能代替位置和覆盖范围比较。
   对有意增删或移动的几何，按登记的预期差异验证，其余范围应保持不变。
3. **填充与标注检查**：核对剖面边界、图案和可编辑对象；受轮廓修改影响的填充允许按要求
   更新。数量仅作诊断，不能把某次项目的尺寸／引线／填充数量写成通用通过条件。
4. **图面与文件检查**：核对最终 PDF／预览中的漏轮廓、空隙、粗黑重线、遮挡、缺字及
   未授权尺寸；重新打开最终 CAD 文件做结构检查。整页像素差异只辅助定位，不证明工程正确。

检查失败时保留失败证据，修复相关原因后重跑受影响项；没有新变化或未解问题时不重复全套检查。
交付说明列出已验证、未验证和被新要求取代的项目，不把“脚本执行成功”当作“图纸要求通过”。

## 4. 在已有 CAD 图纸上局部修改与续作

**默认工作准则：对已制作或交付的图纸，直接以当前有效的 DWG／DXF 为基础做局部修改，
保留已有排版和编辑成果。** 新图可从规格生成；日常批注、尺寸位置、轮廓、剖面等局部修订
不需要重新生成整张图，也不要求先把现有图纸逆向重建成完整 `DrawingSpec`。

### 确定本轮基准

- 优先使用用户本轮指定或亲自修改后的 CAD 文件；没有新版本时，使用上次经核验交付的版本。
  结合文件来源、内容和批注所依据的版本判断，不能只按文件名或修改时间选“最新”。
- 记录基准路径、哈希、版本关系以及相应 PDF。已有未保存编辑时保留现场；未经判定不能
  用磁盘旧文件覆盖当前编辑。只有基准无法确定且会影响结果时，才就具体冲突询问用户。
- 在副本上改动并保存为新修订版本，保留原版以便核对。用户明确要求原位修改时沿用要求，
  同时保留可恢复的基准记录。

### 只执行需要的修改

优先使用能保留原对象的 CAD 原生编辑能力。现有 DWG 无需为了编辑而先转成 DXF；
确需中间格式时，转换前后核对原生尺寸、引线、填充、块、样式、布局及实际使用的关联数据。
不因工具限制而静默炸开、重画或降级对象。按批注 ID 记录增删改对象，保留无关区域和
历史有效要求；修改轮廓后检查受影响的相邻填充与标注，不假定它们一定自动更新。

正式 DXF、PDF 和预览从本轮修改后的 CAD 派生，记录它们对应的源版本；不能交付
“新 DWG 配旧 PDF”。重新打开结果文件，执行第 1—3 节中与本次变更相关的验收。

### 规格与旧脚本的地位

当前 CAD 是本轮编辑依据，旧规格／旧脚本仅用于查证来源和复用计算。能够准确表达本轮
修改时，同步记录参数差异和版本；不能完整表达时，明确标记规格滞后或不完整。后续运行
生成器前，必须核对其基准是否匹配最新 CAD，并先纳入所有有效修改；不能用旧脚本覆盖
用户调整的标注、布局和几何。

仅在用户要求重绘、已证实整体结构变化需要重建，或源文件无法恢复且没有可用的局部编辑
路径时，才考虑重新生成。说明原因、影响范围及需要保留的内容，优先只重建必要部分；
不得以“脚本更方便”为由重画整图，也不能在缺失关键工程数据时猜测重建。

### 保存续作进度

在任务的现有进度记录中保存：本轮基准及最新通过核验的 CAD 路径／哈希、已完成和待处理
批注、仍有效的旧要求、待解决问题、核验结果、派生文件是否已更新，以及下一步动作。
保存节点以完成一项实质修改或即将中断为准，不要求每次工具调用都生成一套日志。
恢复时先核对当前文件是否又被用户修改；一致则接着处理未完成项，已变化则协调版本，
不重复已验收工作，也不盲目重放整套脚本。额度不足时保存进度，依已授权的续作安排等待
恢复，不使用额外重置券；全部完成后结束本任务的续作安排。

这条准则减少的是重复绘制、排版、重新定位和全量生成的工作。所请求格式的导出、
实际文件检查，以及可能受影响的邻近结构核对仍保留；不承诺每种修改都能减少固定比例的时间。

## 实现与评估边界

将上述方法实现为共享模块时，优先复用已经验证的项目逻辑，移除固定坐标、实体索引、
文本内容和实体总数等项目专用条件。案例数据留在测试夹具中，技能正文只保留适用条件和不变量。
方法文档更新本身不构成代码功能实现。

用少量真实案例评估：连续两轮修改后旧批注仍满足；尺寸／引线抽样拖动符合约定；
分段前后覆盖不变且再次执行不继续碎化；无关区域的螺钉、剖面和已删除标注不发生回退。
新增案例要验证可观察行为，避免只匹配文档中的用词。

## 局部核对工具

第 3 节的相邻区域检查可调用 `review`，开工前的环境检查可调用 `doctor`；
见 [命令与边界](review-and-environment.md)。自动结果为候选问题，结合有效批注验收，
不会自行修改轮廓或填充。

批注逐条核验和跨轮次自动重查已接入工具，见 [批注台账](comment-ledger.md)。

## 关联图、样图与共享预览工具

相关零件或视图存在同一参数时，用显式关联清单核对真实几何；授权范围外的图纸只报告待同步。
参考样图时分别记录画法、保留的本图尺寸和已获授权采用的样图尺寸，不从相似外观推断参数。
统一预览检查实际字体、字形、白色遮罩和相同局部比例；预览成功不替代原生 CAD 交互核验。
常用删除、局部轮廓替换和尺寸端点重测直接接入现有修订工作流；分段后保留最终子段映射。
实际命令和严格字段见 [关联、参照、预览与常用修改](drawing-comparison-and-edits.md)。
